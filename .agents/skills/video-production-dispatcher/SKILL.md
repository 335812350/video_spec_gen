# 视频生产调度层 Skill

## 定位

本 Skill 是视频生产平台的唯一推荐入口，负责识别用户意图并选择一条主生产工作流。它不负责完成具体视频的文案、分镜、剪辑或渲染，也不替代被选中的生产工作流。

`video-spec-builder-personal` 属于第二层的影片素材生产工作流；直接调用它仍然保持兼容。通过本调度层进入时，调度结果作为上下文传给被选工作流，由工作流负责自己的追问、研究、创作和规格编排。

## 何时使用

当用户提出以下请求时使用：

- 想制作、改编、剪辑或渲染一个视频，但尚未明确应调用哪条生产工作流；
- 已提供视频类型、平台、时长、素材来源等信息，需要判断合适的生产工作流；
- 需要把模糊的视频想法整理为可确认的工作流选择。

如果用户已经明确要求调用某个具体生产工作流，可以直接加载该工作流；不需要再次把同一请求路由一遍。

## 核心职责

1. 读取用户意图、内容来源、目标平台、时长、受众、交付约束和已有素材。
2. 判断用户是否明确指定视频类型或生产方式。
3. 根据 `references/workflow-registry.md` 选择一条主生产工作流。
4. 对有歧义的请求给出候选工作流和选择理由，请用户确认；低风险情况下可回退到 `generic-video`。
5. 对尚未注册的类型明确说明当前未实现，并推荐最接近的已注册工作流或通用回退；不得伪装成已支持。
6. 将路由上下文交给工作流，并要求最终产出统一 `video-spec` 交付格式。
7. 保留路由结果，包括 `workflow_id`、匹配理由、置信度、用户确认状态以及未解决约束。

## 路由规则

按以下优先级判断：

1. 用户明确指定且已注册的类型或工作流：选择对应条目。
2. 用户明确指定但未注册的类型：说明未实现，推荐最接近的已注册条目；用户接受后才回退或继续。
3. 用户只描述素材和目标、未指定类型：推荐 `generic-video`，并询问是否需要高能混剪等特定风格。
4. 用户的输入、工具链或输出要求明显超出普通工作流：只有注册表标记为独立重型工作流时才路由到该条目；否则先回退到通用工作流并说明边界。
5. 用户明确覆盖推荐：尊重用户选择，但仍将不匹配风险写入路由上下文，并由工作流继续确认。

可复用的 TTS、字幕、素材检索、音频混音和 HyperFrames 能力是工作流内部能力或子流程，不应被误判为顶层视频生产工作流。

## 路由上下文

传给生产工作流的最小上下文包括：

```yaml
workflow_id: high-energy-clip
workflow_version: "2"
video_type: high-energy-clip
production_mode: asset-led
source_film_slug: null
project_slug: null
platform: null
duration: null
audience: null
user_constraints: []
route_reason: "用户明确要求高能混剪"
route_confidence: confirmed
user_confirmed: true
unresolved_questions: []
```

字段为空时由被选工作流继续追问；调度层不提前替工作流完成创作决策。

## 工作流调用协议

完成路由后：

1. 加载所选工作流的 `SKILL.md` 及其直接引用的规则。
2. 传递路由上下文，不重写工作流内部步骤。
3. 由工作流完成需求采访、研究、叙事、文案、素材策略、分镜、音频和剪辑规划。
4. 工作流输出统一的 `video-spec.md`，并包含工作流身份字段。
5. 按现有项目约定由用户确认后，进入 HyperFrames 的 lint/check/preview/render 流程。

调度层不直接修改 `video-spec.md`，不调用 HyperFrames 进行渲染，也不管理工作流内部的运行进度、重试或 checkpoint。

## 兼容行为

- 直接调用 `video-spec-builder-personal` 时，保留其原有 0-1 和迭代流程。
- 直接进入现有类型模块时，保留类型模块的规则；本 Skill 只在需要选择入口时介入。
- 未注册类型不产生虚假的 `workflow_id`，也不生成暗示已支持的承诺。

## 输出要求

调度完成后，先向用户展示：

- 识别到的需求摘要；
- 推荐或确认的 `workflow_id` / `video_type`；
- 选择理由和置信度；
- 已知约束、风险和待确认问题；
- 下一步将加载的生产工作流。

只有在用户确认，或请求足够明确且无高风险歧义时，才继续加载生产工作流。
