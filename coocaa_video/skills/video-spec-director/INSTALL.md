# 安装说明

## 当前项目安装（推荐）

```powershell
npx skills add https://github.com/335812350/video_spec_gen --skill video-spec-director --agent codex --copy --yes
```

## 全局安装（备选）

```powershell
npx skills add https://github.com/335812350/video_spec_gen --skill video-spec-director --agent codex --global --copy --yes
```


该 Skill 与内部 `.agents/skills/video-spec-director` 保持能力一致，用于完整视频规格生成、素材研究、分镜编排和迭代。
