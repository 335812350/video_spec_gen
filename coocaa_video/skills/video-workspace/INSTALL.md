# 安装说明

本目录属于 `coocaa_video/skills/` 分发结构。

## 当前项目安装（推荐）

```powershell
npx skills add https://github.com/335812350/video_spec_gen --skill video-workspace --agent codex --copy --yes
```

## 全局安装（备选）

```powershell
npx skills add https://github.com/335812350/video_spec_gen --skill video-workspace --agent codex --global --copy --yes
```

安装后，新建一个空文件夹并用 Codex 打开，对 Codex 说：

```text
把当前文件夹初始化成视频创作工作区
```
