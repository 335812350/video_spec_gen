# 替换模块 B：当代改编观察旁白（1:30-3:25）

本模块与 narration-module-culture.md 二选一。目标是解释“本剧具体改写了什么”，所有判断均标为编辑解读，不代替片方阐释。

如果说传统白蛇传最容易被记住的，是相爱、阻隔和雷峰塔，那么《浮生之白蛇前缘》先把问题换了一步：白素贞不是为了爱情才去找许仙，她是带着失去的记忆，去完成一段必须偿还的恩。

这个变化很关键。爱情不再是故事唯一的起点；报恩、命令和记忆缺口先把两个人推到一起。她不知道自己忘了什么，他又背着捉妖师与灭门之痛的身份。相遇因此不只是一见钟情，也是一场互相试探。

第二个变化，是许仙的位置。公开简介把他设定为捉妖师，这让“人妖相恋”的老问题不再只发生在旁人的阻拦里，而是直接落进两位主角之间。一个必须寻找，一个可能必须防备。靠近本身，就带着冲突。

第三个变化，是关系的重心从两个人扩展到四个人。小青不是装饰性的同伴，法海也不只是最终出现的阻碍。陪伴、戒律、仇恨和报恩同时进入故事，白蛇传的旧框架便有了更复杂的判断：不是谁爱谁就够了，而是谁愿意承担选择之后的代价。

这当然是基于公开设定做出的编辑解读，具体人物关系还要等正片展开。但它已经给了一个足够清楚的信号：这次的白蛇故事，想讲的不只是“能不能在一起”，而是“当真相并不完整，人该怎样决定相信谁”。
