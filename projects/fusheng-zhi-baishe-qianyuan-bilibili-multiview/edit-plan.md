# 《浮生之白蛇前缘》B站多视角解读：编辑计划

## 项目定位

- 项目：fusheng-zhi-baishe-qianyuan-bilibili-multiview
- 成片：16:9、30 fps、240.0s、B站文化解读
- 目标：让熟悉白蛇人物、但不了解本剧设定和版本流变的观众，对《浮生之白蛇前缘》产生观看兴趣。
- 语气：纪录片式冷静叙述；不把剧集讲成剧情流水账，也不把民俗史讲成百科条目。
- 主题：Folk Frequency；墨绿、纸白、朱砂红为视觉锚点，民俗纹理服务信息，不做仿古滤镜堆叠。

## 母版结构

这不是一条把三个话题硬拼在一起的视频。它是一个可批量生产的母版：每次成片只装入一个替换模块。

| 区段 | 时长 | 是否共用 | 内容职责 |
|---|---:|---|---|
| 共同主叙事 | 0:00-1:30 | 是 | 白素贞失忆、报恩、许仙的捉妖师身份与四人关系，提出“旧传说为什么还要重写”的问题。 |
| 替换模块 A | 1:30-3:25 | 二选一 | 文化考古：白蛇传的民间传播、文本沉淀与舞台/影像再生产。 |
| 替换模块 B | 1:30-3:25 | 二选一 | 改编观察：本剧如何把“前缘”改写成记忆、创伤、身份和判断。 |
| 共同收束 | 3:25-4:00 | 是 | 回到具体剧集，用未解的选择而非硬广收尾。 |

不要把 A 和 B 拼进同一条 240 秒成片；那会把中段压扁成观点清单。A、B 是两条各 240 秒的可替换版本，共享 125 秒主叙事与收束。

## 叙事弧线

1. 钩子：被讲了千年的白蛇传，今天为什么仍能长出新故事。
2. 主线：白素贞先失去记忆，才被要求报恩；许仙又不是传统版本里的单纯书生。
3. 替换视角：A 版回答“这个故事从哪里来，为什么不断被讲述”；B 版回答“这部剧具体改写了什么，为什么不是旧瓶装新酒”。
4. 收束：不替观众下结论，留下“她会想起什么、他会相信什么”的观看动机。
